# Code of Conduct

## Our pledge

We want Forged with Foundry to be a welcoming, harassment-free space for
anyone learning or contributing AI governance control demos, regardless of
experience level, background, or identity.

## Expected behavior

- Be respectful and constructive in issues, pull requests, and discussions.
- Critique ideas and implementations, not people.
- Accept differing viewpoints and experience levels gracefully.
- Focus feedback on the control's correctness, clarity, and scope.

## Unacceptable behavior

- Harassment, insults, or personal attacks of any kind.
- Publishing others' private information without consent.
- Sustained disruption of issues, pull requests, or discussions.

## Scope

This Code of Conduct applies within all repository spaces (issues, pull
requests, discussions) and when representing the project in public spaces.

## Reporting

Report unacceptable behavior by opening a
[GitHub issue](../../issues/new) tagged `conduct`, or, if the report involves
sensitive details you don't want posted publicly, use
[GitHub's private vulnerability/abuse reporting](../../security/advisories/new)
so a maintainer can follow up privately.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, issues, and
other contributions that violate this Code of Conduct, and may temporarily or
permanently restrict contributors for behavior they deem inappropriate,
threatening, or harmful.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

# Ignite 2026: impact of new Microsoft features on Forged with Foundry controls

**Source:** [Microsoft Ignite 2026 Book of News](https://news.microsoft.com/events/ignite/2026/book-of-news/) (Ignite took place 17 to 20 November 2026; read on 25 November 2026).
**Scope:** every announcement in the Book of News, compared with the 20 implemented, validated or in-progress controls and the 141 planned controls in this repository.

> **Read this first.** This overview is based on the Book of News only. No feature listed here was tested in this repository. Before changing a control, confirm on Microsoft Learn that the feature exists, check its support status, regions and licence (several Agent 365 features need an Agent 365 or ME7 licence, and Frontier features need enrolment), and record the result in the control's `ASSESSMENT.md`. Wording such as "will" in the Book of News means the capability is not yet available. Following the repository rules, GA capabilities can enter a core demo; preview and Frontier capabilities belong in **Further exploration** until they are GA or the assessment justifies them.

## 0. Verified outcomes (25 November 2026)

The first three recommendations were checked against Microsoft Learn and recorded in each control's `ASSESSMENT.md` (section "Ignite 2026 re-assessment"). In all three cases the authoritative core path is unchanged; the new features are documented as Further exploration.

| Control | Decision | Main reason (Learn) |
|---|---|---|
| [DAT-PRE-002](../controls/data_and_knowledge/DAT-PRE-002_data_classification_missing/ASSESSMENT.md#ignite-2026-re-assessment) | KEEP | Auto-labeling needs an E5-level licence and a tenant-wide policy with a simulation run, and still leaves some files unlabeled (open, locked, unsupported). It reduces the control's signal; it does not replace it. |
| [QLT-001](../controls/grounding_and_quality/QLT-001_hallucination_rate_high/ASSESSMENT.md#ignite-2026-re-assessment) | KEEP | Insights are GA but documented as "decision support, not authoritative classifications" that must not be the only control. Conversation-level groundedness would hide which response was ungrounded. Status stays `Validated`. |
| [VAL-002](../controls/value_adoption_and_finops/VAL-002_benefits_realisation_gap/ASSESSMENT.md#ignite-2026-re-assessment) | KEEP | Business Analytics is a Frontier portal app without a documented export API; its assisted hours are a Microsoft estimate, not the business case's planned benefit. |

## How to read the tables

| Impact | Meaning |
|---|---|
| **Re-assess** | The feature may provide the control's signal, decision or evidence directly. Review `ASSESSMENT.md` before more work on the control. |
| **Extend** | Useful addition for **Further exploration**; the current core path stays valid. |
| **New demo** | Makes a planned control buildable as `DEMONSTRATE` or `COMPOSE` with a supported capability. |
| **Watch** | Relevant, but not yet available enough (private preview, Frontier, or "will" wording). |

# VAL-001 development

This project was built with the microsoft-foundry skill. Before working on
or answering questions about Foundry agents, read the microsoft-foundry skill
first. If you are in VS Code, read the vscode-microsoft-foundry skill first.

Preserve one monitored helpdesk workload and one deterministic KPI decision.
Do not add ACS inline gates, explanatory agents, model evaluators, shared
frameworks, production actions, or a VAL-001 declaration schema. Target and
owner come from the existing VAL-PRE-001 contract through the shared validator.
Only executed and verified synthetic resolutions count as deflected.
Never enable sensitive-content tracing. Never treat HTTP acceptance as Teams
delivery. Keep status Planned until the documented live path and cleanup pass.

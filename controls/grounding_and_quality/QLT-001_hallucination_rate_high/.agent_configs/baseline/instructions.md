This IT helpdesk agent answers questions about vpn_setup, password_reset, or license_renewal by calling a lookup_it_kb tool with a topic and a window number (1-4), then answering only from what that tool returns. Requests are JSON like {"window": 1, "topic": "vpn_setup"}. In windows 1-2 the tool returns a full current KB article; in windows 3-4 it returns a shortened article or NO_CURRENT_ARTICLE, and a correct answer must say no current article is available rather than inventing details.
